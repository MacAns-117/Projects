<h2>The question</h2>

<p>Forage / PwC <strong>Power BI in Data Analytics</strong> virtual experience, completed <strong>November 2022</strong>. It has three tasks. Each one gives you a dataset and asks for a Power BI report on it.</p>

<p>The datasets are practice data supplied by the programme. This is a practice project, not client work.</p>

<h2>How to open</h2>

<p>GitHub cannot preview <code>.pbix</code> files. To view a report:</p>

<ol>
  <li>Install <a href="https://www.microsoft.com/power-bi/desktop">Power BI Desktop</a> (free, Windows).</li>
  <li>Download the <code>.pbix</code> file and the <code>.xlsx</code> dataset from the same folder.</li>
  <li>Open the <code>.pbix</code> in Power BI Desktop. If it asks for the data source, go to <strong>Transform data &gt; Data source settings</strong> and point it at the downloaded <code>.xlsx</code>.</li>
</ol>

<p>The <code>.xlsx</code> files open in Excel or any spreadsheet program.</p>
