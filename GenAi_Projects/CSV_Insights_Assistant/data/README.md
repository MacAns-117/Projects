# Data

| File | What |
| --- | --- |
| `hotel_bookings.csv` | Default demo. Antonio, Almeida & Nunes, *Hotel booking demand datasets*, Scientific Data (2019). Two Portuguese hotels, arrivals July 2015 – August 2017. 119,390 raw rows. Loader drops exact duplicates and all-zero guest rows → **87,230**. |
| `sample_sales.csv` | Tiny fake table (10 rows) so you can see a second schema without the hotel columns. |

The agents do not assume hotel column names. Whatever CSV is loaded is the table.
